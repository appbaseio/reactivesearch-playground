# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not** open a public GitHub issue for security-sensitive reports.

Instead, please email the maintainers with:

- A description of the vulnerability
- Steps to reproduce the issue
- Any potential impact you have identified
- Suggested fixes (if you have them)

We will acknowledge receipt of your report and work to understand and address the issue. We ask that you allow reasonable time for a fix before any public disclosure.

## Supported Versions

Security fixes are applied to the latest release. Older versions may not receive patches.
